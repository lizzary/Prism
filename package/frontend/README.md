# Prism 前端

React 19 + Vite 8（纯 JavaScript）。

```bash
npm install
npm run dev      # http://localhost:5191
npm run build    # 产物在 dist/，放到 .exe 同级的 frontend/ 目录即可被后端代理
```

## 分层（UI 与数据分离）

| 目录 | 职责 |
| --- | --- |
| `src/ui/` | 只做界面与交互：页面（home / group（含灯箱）/ login）、浮层（search / tags / tasks / settings / editors / colors / export / backup / mcp / welcome）、组件、图标、星月夜画作 |
| `src/bridge/` | 中间层：React hooks（Suspense 页面数据、按主题失效的缓存、分组页的定时刷新 `feed.js`、实时任务/设置/访问/模型 store、乐观更新的页面设置） |
| `src/data/api/` | 数据层对外 API，UI 只经由 bridge 调用这里；每个接口的数据结构写在 `data/api/index.js` 的注释里 |
| `src/data/domain/` | 业务规则：搜索（各搜索域取并集）、标签的规范化与合并、画质档位与文件类型、分组页的浏览顺序（`arrange.js`：排序、颜色组、每组限量、收起、分页、拖动后的新顺序）、导出的键（`keys.js`）、文件名模板校验（`filename.js`）与目录规划（`exportPlan.js`） |
| `src/data/mock/` | 本轮的模拟后端：`backend.js`（分组、文件、颜色组、媒体地址、搜索、标签、任务、上传、下载、导出、文件夹、模型、设置）、`access.js`（密码登录、服务器模式、MCP 密钥、首次启动）、`snapshots.js`（数据备份快照）、`seed.js` + `content.js`（可确定生成的样例图库）、`art.js`（代替真实图片的 SVG 画作）、`files.js`（在浏览器里读取上传文件的尺寸与视频封面帧、把生成的画作渲染成可下载的文件）、`persist.js`（代替 config.toml 与数据库里的页面设置）。接入 Go 服务时把 `data/api` 引用的这几个模块（backend · access · snapshots · files）换成 HTTP/SSE 客户端即可 |

## 约定

- 路由为 hash：`#/`、`#/group/:id`、`#/group/:id/file/:fileId`（在分组里打开某个文件，即灯箱），任何目录下都可直接托管。灯箱属于分组页：打开、切换、关闭灯箱时分组页不会重新进入、也不会滚动；在灯箱里切换文件替换当前历史记录，所以“后退”直接离开灯箱。
- 字体只使用 `public/fonts/` 中的三款 TTF（源文件在 `font/`）；图标全部来自 `src/ui/icons/Icon.jsx`（项目标志在 `Logo.jsx`），禁止 emoji。
- 文件的图片地址一律通过 `bridge` 的 `mediaUrl(file, quality)` 取得（`original` / `high` / `medium` / `low`），UI 不拼接后端地址；分组封面固定使用 `original`。
- 首页星月夜：`src/ui/art/starry/`，原样复用自 PostPock（厚涂引擎移植自 The Pelican Test 第 12 幕，MIT）。在 Web Worker 中绘制并缓存到 IndexedDB（`prism-art`），之后访问直接解码。
- 文案在 `src/i18n/`（English / 简体中文），两份词典的键保持一致。默认语言为 English；深浅色在首次启动时跟随系统。
- 浮层（搜索、标签一览、设置、分组编辑……）在页面空闲后预先加载，连同它们一打开就要显示的数据；打开浮层的入口加上 `data-overlay="名称"`，指针移向入口时就会提前加载，这样第一次打开也有完整的入场动画。
- 有遮罩的浮层打开时，首页的星月夜会暂停，避免在模糊遮罩下逐帧重绘：画作有自己的时钟，休息时时钟停住，画面仍完整（旋涡、星、月、柏树、窗户都在），关闭后从同一刻继续。首次启动时引导一开始就盖住页面，画作在引导下完整地静止，关闭后才开始转动，村庄的窗户随后分几波亮起。
- 实时 store（任务、设置、访问、模型）只在值真的变化时通知订阅者；语言变化通过 `language` 主题让所有查询重新取数（数据层返回的文字随语言变化），其余设置不会触发整体刷新。
- 设置项点击后立即生效、在后台保存（数据层的乐观更新：保存失败会恢复原值，连续快速切换不会闪回）；切换数据库路径除外，它会重新载入图库，等后端完成。主题切换在圆形揭示动画的更新里提交，开关与页面一起换到新主题。组件可以用 `useSetting(key)` 只订阅某一项设置（应用外壳只读主题和语言）。
- 浮层之间可以交接：`useOverlays().handOff(from, to)` 让一个浮层让位给另一个，后者关闭时回到前者（设置 → 数据备份 / MCP 密钥 → 关闭后回到设置的同一分组）。交接时遮罩保持不变，只有面板移动；从浮层里点链接离开（`onLeave`）则不会回去。
- 选择分组一律使用 `ui/components/GroupSelector.jsx`：`GroupSelector` 是一面可勾选的封面墙（搜索、Shift 连选、全选/全不选、底部叠放已选封面），`GroupsField` 是它的摘要入口（扇形叠放的封面、名称与总数、可选的“全部分组”）。导出、MCP 密钥、创建快照都用它。
- 选择文件夹一律使用 `ui/features/folders/FolderPicker.jsx`（带 `accept` 时也能选文件，例如快照文件 `.prsnap`）。

## 首页

- 分组墙：封面默认按原始比例排成“两端对齐”的行（`ui/lib/justify.js`，极端比例收进 0.5–2.4 之间裁切显示）；分组栏上的图标开关可切换为统一方形。每张卡片都由计算出的位置摆放，切换排版、拖动排序、查找、新增或删除分组时卡片会滑到新位置。
- 在封面上左右移动指针，可以快速翻看分组里的几张图片（首次悬停时才加载）。
- 拖动卡片排序，松手后卡片从松手的位置滑入新位置；查找分组时暂停拖动。
- 分组栏里是整面墙的缩略条：每个分组一个小封面，顺序与墙一致；当前在屏幕上的分组被一个柔和的光框框住，随滚动移动；点击小封面会滚动到该分组并让它亮一下。
- 上次浏览显示所在分组和它在分组中的位置；随机一张会洗一遍牌，再打开抽到的文件。

## 分组页

- 头部是分组封面（原图）的宽幅横幅，向下融入页面并随滚动轻微视差；从首页点进分组时，卡片封面会变形为横幅（共享名称 `group-art-<id>`），返回时落回卡片。没有封面的分组不显示横幅。
- 工具栏吸附在顶栏下方，分三簇（由安静到显眼）：颜色组（当前配置的色点与名称，可切换配置或打开颜色组编辑；排版：单行 / 双行 / 混合排列；每组限量；全部收起 / 展开）、外观（排序与升降序、5 档尺寸滑杆、原比例 / 方形、画质与每页文件数）、操作（刷新环、白板、上传）。
- 刷新：页面每 5 秒向数据层要一次（带上已有数据的版本号，图库没有变化时只回一个版本号）。刷新环随时间填满，到点即刷新，点击立即刷新；窗口在后台或正在拖动时暂停，新到的文件会亮一下，工具栏显示“新增 N 个”。自己上传的文件在上传完成时立即刷新。
- 布局（`ui/pages/group/layout.js`）：所有图块、颜色组底色、标题都由计算得出的位置摆放，切换排序、尺寸、排版时图块滑到新位置；只渲染屏幕附近的图块，几千个文件也流畅。单行：每个颜色组一个带标题的色块；双行：两个颜色组平分一行（同一行的两个色块等高）；混合排列：颜色组紧接着排列，每段上方有一个小标签，跨行的一段在行尾开口、在下一行开头接上，下一行的标签带“接上一行”的折行图标。收起的颜色组在单 / 双行里只剩标题（并带几张缩略图），在混合排列里缩成一张小卡。
- 每组限量：每组只显示前 N 个，末尾一张“+N”卡（扇形叠放后面几张）可展开该组；展开后标题上可收回到 N 个。限量与展开状态、收起状态、排序、尺寸等都按分组独立保存（乐观更新）。
- 选择：Ctrl / Shift 单击、图块左上角的圆圈、Ctrl A（本页）；被选中的图块缩进一个星光色的浅槽并打勾，底部升起操作栏（下载、重新索引、删除），Esc 取消选择，Delete 删除（需确认）。右键或图块右上角的“更多”打开菜单：打开、选择、设为封面（仅图片）、下载、重新索引、删除。
- 拖动：拖动一个（或已选中的一批）文件到新位置，排序自动切换为自定义排序（可撤销）；移入另一个颜色组（包括拖到标题或空颜色组上）时先弹出确认，按来源颜色组列出将要移动的文件。拖动颜色组标题可调整颜色组顺序。拖动时页面靠近上下边缘会自动滚动，Esc 取消。
- 删除：图块菜单和底部操作栏的删除需要二次确认（扇形叠放将被删除的文件）；删除后可在提示里撤销。重新索引弹出选择：标签（保留手动标签）、图像索引、元信息，标签模型未下载时标签项不可选并引导到设置。
- 上传：上传按钮或把图片 / 视频拖到页面任意位置（页面内部的拖动不会触发）；非图片或视频的文件会被略过并提示。
- 下载：使用设置里的“下载文件命名”。单个文件直接保存；多个文件由“打包下载”任务完成（任务面板显示进度）。
- Ctrl + 滚轮在文件上调整图块尺寸；页面顶部的分页安静小巧（‹ 2 / 7 ›），底部是完整的页码。

## 灯箱

- 夜色房间：深色背景上铺一层由当前图片模糊而成的微光，控件在指针静止约 2.6 秒后隐去。默认按最大可用尺寸显示；从图块打开 / 关闭时图片从图块的位置放大 / 缩回；从首页“上次浏览”打开时与首页的缩略图共享名称 `file-art-<id>`。
- 缩放：滚轮以指针为中心缩放，放大后可拖动，双击在适应屏幕与放大之间切换；右下角安静的缩放条（拖动条、百分比、一键回到适应屏幕）。
- 切换：←→ / ↑↓、两侧的箭头、Home / End，顺序与分组页的浏览顺序相同（包括被收起或限量隐藏的文件）。关闭时分组页翻到该文件所在的一页并滚动到它，让它亮一下。
- 幻灯片：选择每张时长（3–20 秒）后开始，空格暂停 / 继续，Esc 停止；每张从夜色中浮现并缓慢推近，底部一条细线显示本张剩余时间，到末尾后从头循环。
- 详情（I 键或右上角）：分组、颜色组（可直接改到其他颜色组）、分辨率、大小、时长、创建日期、上传日期、标签与备注（可编辑保存；手动标签为暖色并带笔形图标，模型标签底部有一条表示置信度的细线；添加标签时从已有标签中提示）、ComfyUI 参数（模型、正 / 负向提示词可复制、种子可复制、采样器、调度器、步数、CFG、降噪强度；没有时不显示）。
- 设为封面、下载、删除（无需确认，可在提示里撤销，删除后自动显示下一个文件）。视频自动播放、循环，底部有安静的播放条。

## 颜色组

- 分组页工具栏的颜色组按钮 → 编辑颜色组（`ui/features/colors/ColorGroupsDialog.jsx`）：左侧是配置列表（新建、切换），右侧是所选配置的颜色组：改名、选颜色（12 种柔和色或任意颜色）、拖动排序、添加、删除（提示其中的文件会离开）。顶部的棱镜把分组的文件按颜色组“分光”成一条色带，随编辑实时变化。保存会保存所有配置并在页面上使用所选的配置（也可以选择不使用颜色组）。

## 模拟层的行为

| 功能 | 模拟层的行为 |
| --- | --- |
| 样例图库 | 27 个分组、约 3400 个文件（含视频、ComfyUI 元信息、模型标签与手动标签、颜色组配置），按当天日期确定生成 |
| 持久化 | 设置（语言、主题）、首页的封面比例、分组顺序、上次浏览存在浏览器存储里（对应后端的 config.toml / sqlite）；新增、修改、删除分组只保存在内存中，刷新后回到样例库 |
| 以文搜图 / 以图搜图 | 需要后端具备图像索引，默认锁定。地址加上 `?image-search`（如 `http://localhost:5191/?image-search#/`）可模拟已建好索引的后端：以文搜图按画面内容与色调匹配，以图搜图按图片的整体色调匹配 |
| 任务 | 预置一个进行中的“重新索引”和一个排队中的“导入文件”；导入运行时文件会逐个加入“未整理”分组，首页的数量随之变化。任务分道执行，每道同时只跑一个：图库（导入、重新索引）、上传、文件（导出、打包下载）、模型下载、快照，互不排队。任务进度最多每 0.5 秒推送一次（开始、结束等状态变化立即推送），避免频繁重绘打断页面切换 |
| 分组页 | 每次修改图库都会更新版本号，分组页每 5 秒带着版本号来要数据，没有变化时只返回版本号。页面设置（排序、排版、限量……）按分组保存在浏览器存储里（对应数据库）；文件的标签、备注、颜色组、自定义顺序与颜色组配置的修改保存在内存中（会出现在数据备份的更改里），刷新后回到样例库。“星空与夜景”“Pixiv 收藏 · 风景”等分组有颜色组配置，“草稿”是空分组 |
| 上传与下载 | 上传的图片 / 视频真的会被读取（尺寸、视频时长与封面帧），在“上传”任务里逐个加入分组，本次会话内可正常浏览；下载单个文件时把生成的画作按原尺寸与格式渲染成文件交给浏览器保存，多个文件以“打包下载”任务模拟 |
| 首次启动引导 | 配置里尚未完成引导时自动打开；地址加上 `?first-run`（如 `http://localhost:5191/?first-run#/`）可再看一次。只有引导结束时才保存选择，密钥除外（点击“创建密钥”时就创建，便于立刻复制） |
| 登录页 | 开启密码登录后打开页面即进入；会话存在 `sessionStorage`，新标签页需要重新登录；“设置 → 访问与安全 → 立即锁定”可直接回到登录页；连续输错 5 次需等待 30 秒。“忘记密码”说明在 Prism 终端输入 `/reset_pwd`，或在 `config.toml` 中关闭密码保护（由后端实现）。模拟层为了校验会保存明文，后端只应保存哈希 |
| 服务器模式 | 设置 → 访问与安全；开启后顶栏出现服务器按钮（地址与二维码）。后端启动时读取该设置，所以开关后要重启才生效；模拟层把“刷新页面”当作重启 |
| MCP | 设置 → MCP → 管理密钥。密钥保存在模拟配置里（样例含 3 个）；完整密钥只在创建与重新生成时返回一次。权限分三类：分组（查询、修改信息、删除）、颜色组（查看、创建、修改信息、删除）、文件（查询、添加、修改信息、删除）；预设“整理”= 查询 + 修改信息 + 创建颜色组 |
| 数据备份（快照） | 设置 → 数据与备份 → 数据备份。备份粒度为分组：创建快照时选择包含哪些分组（默认选中有更改的分组，已删除的分组也可选，以便保存删除）；页面设置与导出配置属于整个图库，总会一起保存。每个快照记录当时的分组与文件：载入较早的快照会让样例库真的回到当时（未保存到快照的内容会丢失），被删除的分组与文件仍由快照保管；删除快照只是从时间线隐藏，可撤销；`D:\Prism\backup` 里预置了一个可导入的 `.prsnap` 快照文件，导出的文件也会出现在所选文件夹中 |
| 导出 | 首页导出整个图库（文件类型来自全部文件），分组页导出已包含当前分组（文件类型来自所选分组）；按导入日期筛选，日历上的点表示当天导入的文件数。默认文件名为“分组名称 / 颜色组名称 / 原文件名”（不属于任何颜色组的文件直接放在分组目录里）。每个页面的上一次配置会记住（乐观保存） |
| 标签模型 | 列表与状态来自后端：EVA02-Large v3 默认已下载并使用中；“重新下载”需二次确认，会先删除模型文件再下载（任务面板与设置里实时显示进度，可取消） |
| 数据库路径 | 设置 → 数据与备份；改为其他目录会切换到一个空库，可用来查看空状态；改回默认路径即恢复样例库 |

## 设置

按功能分为六组：

| 分组 | 设置项 |
| --- | --- |
| 常规 | 语言、主题、白板渲染器（自动选择 / WebGL / DOM；“自动”会显示当前设备将使用哪一种，设备不支持 WebGL 时该选项不可选） |
| 数据与备份 | 数据库路径（文件夹选择器）、数据备份入口（迷你时间线：每个快照按日期排布，柱高表示保存了多少更改，末尾是“现在”） |
| 文件 | 文件名冲突处理（保留 / 跳过 / 覆盖，下方用两个同名文件演示结果）、下载文件命名（与导出文件名相同的编辑器，但只有数据键、不能包含路径，下方用三个真实文件实时预览） |
| 模型 | 标签模型列表（下载 / 下载中 / 已下载 / 使用中，重新下载需确认）、GPU 加速（显示检测到的显卡） |
| 访问与安全 | 密码登录（设置、修改、关闭、立即锁定）、服务器模式（地址与二维码、等待重启的状态） |
| MCP | MCP 服务开关与服务地址、密钥管理入口 |

## 阶段说明

第一、二、三阶段已完成（基础设施、主页面；设置、MCP、数据备份、服务器模式、导出、登录页、首次启动引导；分组页、灯箱、颜色组编辑）。白板在第四阶段完成，分组页工具栏的“白板”入口目前提示“这部分还在制作中”。
