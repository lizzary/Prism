# Prism 前端

React 19 + Vite 8（纯 JavaScript）。

```bash
npm install
npm run dev      # http://localhost:5191
npm run build    # 产物在 dist/，放到 .exe 同级的 frontend/ 目录即可被后端代理
```

## 分层（UI 与数据分离）

| 目录 | 职责 |
| --- | --- |
| `src/ui/` | 只做界面与交互：页面（home / group（含灯箱）/ login）、浮层（search / tags / tasks / settings / editors / colors / export / backup / mcp / welcome）、组件、图标、星月夜画作 |
| `src/bridge/` | 中间层：React hooks（Suspense 页面数据、按主题失效的缓存、分组页的定时刷新 `feed.js`、实时任务/设置/访问/模型 store、乐观更新的页面设置） |
| `src/data/api/` | 数据层对外 API，UI 只经由 bridge 调用这里；每个接口的数据结构写在 `data/api/index.js` 的注释里 |
| `src/data/domain/` | 业务规则：搜索（各搜索域取并集）、标签的规范化与合并、画质档位与文件类型、分组页的浏览顺序（`arrange.js`：排序、颜色组、每组限量、收起、分页、拖动后的新顺序）、导出的键（`keys.js`）、文件名模板校验（`filename.js`）与目录规划（`exportPlan.js`） |
| `src/data/mock/` | 本轮的模拟后端：`backend.js`（分组、文件、颜色组、媒体地址、搜索、标签、任务、上传、下载、导出、文件夹、模型、设置）、`access.js`（密码登录、服务器模式、MCP 密钥、首次启动）、`snapshots.js`（数据备份快照）、`seed.js` + `content.js`（可确定生成的样例图库）、`art.js`（代替真实图片的 SVG 画作）、`files.js`（在浏览器里读取上传文件的尺寸与视频封面帧、把生成的画作渲染成可下载的文件）、`persist.js`（代替 config.toml 与数据库里的页面设置）。接入 Go 服务时把 `data/api` 引用的这几个模块（backend · access · snapshots · files）换成 HTTP/SSE 客户端即可 |

## 约定

- 路由为 hash：`#/`、`#/group/:id`、`#/group/:id/file/:fileId`（在分组里打开某个文件，即灯箱），任何目录下都可直接托管。灯箱属于分组页：打开、切换、关闭灯箱时分组页不会重新进入、也不会滚动；在灯箱里切换文件替换当前历史记录，所以“后退”直接离开灯箱。
- 换页面（首页 ↔ 分组页）是 transition，旧页面留到新页面准备好再交叉淡化（文档级 view transition）；同一页面之内的路由变化（打开、切换、关闭灯箱）是普通更新，不启动 view transition——否则整页快照会把带名字的顶栏（和分组横幅）抬到灯箱上面，直到过渡结束才突然消失。灯箱打开时顶栏的 `view-transition-name` 也为 `none`，从首页直接打开文件时同理。
- 有遮罩的浮层（对话框、Sheet、搜索）打开时发生的换页（首次启动时首页在引导下面到达、从搜索打开分组……）同样是文档级 view transition，而它会把所有带名字的元素（页面本身、顶栏、封面）画在整个文档之上、盖住浮层，直到过渡结束。所以浮层用 `useModalLayer`（`ui/components/overlay.jsx`）：打开期间根元素带 `data-modal`，页面里的元素不再带名字，页面在遮罩下整体交叉淡化；浮层的面板自带一个名字，始终在最上面、保持实时（`base.css`）。新的有遮罩的浮层也要用它。
- 共享元素的两端必须在同一次提交里出现：首页的分组墙在第一次渲染时就按上次量得的宽度（首次进入时按视口估算，绘制前校正）摆好卡片，所以从分组页回到首页时，横幅能落回卡片。灯箱同理：舞台尺寸在第一次渲染前就按窗口算好（`Lightbox.jsx` 的 `stageRoom`，与 `.stage` 的内边距对应），图片在换页的那次提交里就已在位。
- 灯箱随页面一起到达或离开（从首页“上次浏览”、随机一张、搜索结果打开文件，或在灯箱里按浏览器后退回到首页）是灯箱自己的换页：路由给这次 transition 加上类型 `file-open` / `file-close`，期间 `#root` 里除了标着 `data-vt-travel` 的缩略图外一律不带名字（页面、顶栏、分组封面都不会被抬到灯箱上面），只有图片在缩略图与灯箱之间飞行（类名 `travel`），其余作为整个文档一起交叉淡化——夜色房间在旧页面上暗下来，或从到达的页面上褪去。React 认为只有带名字的部分变化时会丢掉文档自身的快照（灯箱经 portal 挂载，它不计入），所以路由在这类换页期间给根元素写上 `view-transition-name: root`，播放完再撤下。灯箱打开期间的任何 view transition 也同样让页面里的元素不带名字（`:root[data-lightbox]`）。
- 换页时新到达的页面（`page-in`）是“新出现的部分”，浏览器把它画在所有延续下来的部分之上。所以顶栏组固定 `z-index: 2`；分组封面回到首页卡片时（卡片一端带 `landing` 类）`z-index: 1`，落在到达的首页之上——否则首页快照里卡片的浅色底框会盖在封面上，像一层白雾。去分组页时横幅仍在页面之下（页面的标题和阴影本该在它上面）。封面变形的两端填满同一个框并裁切（`overflow: clip`），不会出现两个不同形状的框。
- view transition 进行时不要锁滚动：根元素 `overflow: hidden` 加上页面已滚动时，Chrome 在过渡结束前不再绘制 fixed 图层（灯箱本身也看不见）。`useScrollLock` 因此等过渡播完才加锁；随页面到达的灯箱也把“分组页跟随到当前图块”和邻近图片的预取推迟到过渡之后（`ui/lib/viewTransition.js` 的 `afterViewTransition`）。
- 字体只使用 `public/fonts/` 中的三款 TTF（源文件在 `font/`）；图标全部来自 `src/ui/icons/Icon.jsx`（项目标志在 `Logo.jsx`），禁止 emoji。
- 文件的图片地址一律通过 `bridge` 的 `mediaUrl(file, quality)` 取得（`original` / `high` / `medium` / `low`），UI 不拼接后端地址；分组封面固定使用 `original`。
- 首页星月夜：`src/ui/art/starry/`，原样复用自 PostPock（厚涂引擎移植自 The Pelican Test 第 12 幕，MIT）。在 Web Worker 中绘制并缓存到 IndexedDB（`prism-art`），之后访问直接解码。
- 文案在 `src/i18n/`（English / 简体中文），两份词典的键保持一致。默认语言为 English；深浅色在首次启动时跟随系统。
- 浮层（搜索、标签一览、设置、分组编辑……）在页面空闲后预先加载，连同它们一打开就要显示的数据；打开浮层的入口加上 `data-overlay="名称"`，指针移向入口时就会提前加载，这样第一次打开也有完整的入场动画。
- 有遮罩的浮层打开时，首页的星月夜会暂停，避免在模糊遮罩下逐帧重绘：画作有自己的时钟，休息时时钟停住，画面仍完整（旋涡、星、月、柏树、窗户都在），关闭后从同一刻继续。首次启动时引导一开始就盖住页面，画作在引导下完整地静止，关闭后才开始转动，村庄的窗户随后分几波亮起。
- 实时 store（任务、设置、访问、模型）只在值真的变化时通知订阅者；语言变化通过 `language` 主题让所有查询重新取数（数据层返回的文字随语言变化），其余设置不会触发整体刷新。
- 设置项点击后立即生效、在后台保存（数据层的乐观更新：保存失败会恢复原值，连续快速切换不会闪回）；切换数据库路径除外，它会重新载入图库，等后端完成。主题切换在圆形揭示动画的更新里提交，开关与页面一起换到新主题。组件可以用 `useSetting(key)` 只订阅某一项设置（应用外壳只读主题和语言）。
- 浮层之间可以交接：`useOverlays().handOff(from, to)` 让一个浮层让位给另一个，后者关闭时回到前者（设置 → 数据备份 / MCP 密钥 → 关闭后回到设置的同一分组）。交接时遮罩保持不变，只有面板移动；从浮层里点链接离开（`onLeave`）则不会回去。
- 选择分组一律使用 `ui/components/GroupSelector.jsx`：`GroupSelector` 是一面可勾选的封面墙（搜索、Shift 连选、全选/全不选、底部叠放已选封面），`GroupsField` 是它的摘要入口（扇形叠放的封面、名称与总数、可选的“全部分组”）。导出、MCP 密钥、创建快照都用它。
- 选择文件夹一律使用 `ui/features/folders/FolderPicker.jsx`（带 `accept` 时也能选文件，例如快照文件 `.prsnap`）。

## 首页

- 分组墙：封面默认按原始比例排成“两端对齐”的行（`ui/lib/justify.js`，极端比例收进 0.5–2.4 之间裁切显示）；分组栏上的图标开关可切换为统一方形。每张卡片都由计算出的位置摆放，切换排版、拖动排序、查找、新增或删除分组时卡片会滑到新位置。
- 封面：每个分组有一组封面（最多 8 张，第一张是主封面），在卡片上左右移动指针按顺序翻看（首次悬停时才加载，原图）。没有选过时由 Prism 自动挑选（最新的一张，再从整个分组里均匀取几张，新上传的图片会成为主封面）；选过之后保持不变。规则在 `data/domain/covers.js`。
- 点开分组时，卡片上正在显示的那张封面变形为分组页的横幅，分组页就停在这张封面上；返回时横幅当前的封面落回卡片，片刻后卡片再慢慢换回主封面（`ui/lib/coverOnShow.js` 在两页之间传递“正在显示的封面”）。
- 拖动卡片排序，松手后卡片从松手的位置滑入新位置；查找分组时暂停拖动。
- 分组栏里是整面墙的缩略条：每个分组一个小封面，顺序与墙一致；当前在屏幕上的分组被一个柔和的光框框住，随滚动移动；点击小封面会滚动到该分组并让它亮一下。
- 上次浏览显示所在分组和它在分组中的位置；随机一张会洗一遍牌，再打开抽到的文件。打开时缩略图（或抽中的那张牌上的图片）飞进灯箱，夜色房间在首页上暗下来；指针移向“上次浏览”、或牌还在洗时，就已经把分组页的数据和灯箱要显示的图片准备好（`ui/lib/prepareFile.js`），所以点下去换页立即开始。在灯箱里按浏览器后退回到首页时，图片落回“上次浏览”的缩略图；返回首页（后退 / 前进）时首页的头部与缩略条不再重播入场动画。

## 分组页

- 分组页使用整个宽度（不受 1520px 的版心限制），宽屏上文件铺满整行；页面通过 `usePageMeta({ wide: true })` 告诉顶栏，顶栏随之铺满，左右边缘与页面对齐。
- 头部是分组封面（原图）的宽幅横幅，向下融入页面并随滚动轻微视差；从首页点进分组时，卡片上正在显示的封面会变形为横幅（共享名称 `group-art-<id>`，两端都是叠放全部封面的容器），返回时落回卡片。没有封面的分组不显示横幅。
- 分组名右侧是封面刻度（两张以上时）：每张封面一道短线，横幅正在显示的那道变粗，留在横幅上的那道为星光色；指针沿刻度移动即在横幅上预览，点击（或方向键）留下这一张；后面的“编辑封面”打开分组编辑并聚焦到封面。新显示的封面在上一张之上淡入，上一张等它完全出现后才撤下。
- 编辑封面（分组编辑对话框）：左侧是卡片的实时预览（可以在上面翻看）；封面排在一条“架子”上，第一张带星，拖动或 Alt ← → 调整顺序，Delete 或悬停时的 × 移出，悬停即在预览里显示，空位显示为浅色虚格；下方是分组里的图片，点击加入（排到最后）或移出，已选的标出序号；“自动”开关交回 Prism 挑选，关掉则把当前自动挑选的几张固定下来；满 8 张时再加入会轻轻晃一下并点亮计数。
- 工具栏吸附在顶栏下方、横跨页面（吸附后底色与分隔线铺满整个宽度）。左侧是颜色组：“列表”按钮（打开文件旁的颜色组列表，见下文）、当前配置的色点与名称（切换配置或打开颜色组编辑）、排版（单行 / 双行 / 混合排列）、每组数量（“全部 | − N + 个/组”，点一下即切换，数字可直接输入或加减）、全部收起 / 展开，接着是颜色组条：按顺序列出每个颜色组（色点、名称、文件数），屏幕上的颜色组被一个柔和的光框框住并随滚动移动，点击即滚动到该颜色组（跨分页时先翻到那一页）并让它亮一下；空间不够时只留色点与数量（悬停显示名称），再窄就让位。右侧是外观（排序与升降序、尺寸滑杆、原比例 / 方形、画质与每页文件数）与操作（刷新、白板、上传）。工具栏变窄时按实测宽度（两种语言）依次收起，每一步都在放不下之前一点：颜色组条 → 白板 / 上传的文字 → 配置名 → 排序的名称（菜单里仍有）、“个/组”与尺寸滑杆两端的按钮，控件间距收紧 → “列表”二字；再窄才换成两行（“列表”的名称回来），任何宽度下都不会溢出。
- 尺寸：5 档按“整行能并排几张”定义——第 5 档 2 张、第 4 档 4 张、第 3 档（默认）6 张、第 2 档 8 张、第 1 档 10 张（整页宽度计；双行时每个颜色组约占一半）。方形时严格如此；原比例时行高按该分组文件的平均比例确定，平均下来每行同样多张。
- 刷新：页面每 5 秒向数据层要一次（带上已有数据的版本号，图库没有变化时只回一个版本号）。刷新图标自己的两段弧线从尾部向箭头逐渐描满，到点刷新时淡去，点击立即刷新（箭头转一圈）；窗口在后台或正在拖动时暂停（变暗、停住），新到的文件会亮一下，图标旁显示“新增 N 个”。自己上传的文件在上传完成时立即刷新。
- 布局（`ui/pages/group/layout.js`）：所有图块、颜色组底色、标题都由计算得出的位置摆放，切换排序、尺寸、排版时图块滑到新位置；只渲染屏幕附近的图块，几千个文件也流畅。三种排版的标题都在颜色组内部的顶端。单行：每个颜色组一个带标题的色块。双行：两列，颜色组按顺序放进当前较短的一列（一样高时放左列）；两列底部相差不多时对齐成一行（较短的色块补齐高度，收起的除外），相差很大时后面的颜色组直接接在较短一列下面，所以收起或很短的颜色组旁边不会留下高高的空色块。混合排列：颜色组紧接着排列，每段色带顶端有一条细标题；跨行的一段在行尾开口、在下一行开头接上，下一行这段的标题带“接上一行”的折行图标。收起的颜色组在单 / 双行里只剩标题（并带几张缩略图）。混合排列里收起（或空）的颜色组没有图片可以撑起一行，所以不占图块位置：相邻的几个一起放在开着的颜色组之间的一层“架子”上，每个是一张与标题等高（46px）的标签——色点、名称、数量，末尾三张扇形叠放的缩略图——按列均匀排开（每列至少 256px），高度与尺寸档位无关；全部收起时整页就是一张整齐的颜色组一览。点击标签（或聚焦后回车 / 空格）展开，拖动标签调整颜色组顺序，把文件拖到标签上即移入该颜色组；空颜色组的标签是虚线框，只用来放入文件。
- 每组限量：每组只显示前 N 个，标题里文件数旁边是一个小标签“+剩余数”，点击展开该组；展开后同一位置变为“⌃ N”，点击收回到 N 个。不再占用图块位置，限 1 张时页面上几乎全是图片。限量与展开状态、收起状态、排序、尺寸等都按分组独立保存（乐观更新）。
- 选择：Ctrl / Shift 单击、图块左上角的圆圈、Ctrl A（本页）；被选中的图块缩进一个星光色的浅槽并打勾，底部升起操作栏（下载、重新索引、删除），Esc 取消选择，Delete 删除（需确认）。右键或图块右上角的“更多”打开菜单：打开、选择、设为主封面 / 加入封面 / 移出封面（仅图片，可在提示里撤销；封面已满时提示并可直接打开编辑封面）、下载、重新索引、删除。封面所在的图块右下角有封面标记，主封面的标记为金色实底。
- 拖动：拖动一个（或已选中的一批）文件到新位置，排序自动切换为自定义排序（可撤销）；移入另一个颜色组（包括拖到标题、收起或空颜色组的标签上）时先弹出确认，按来源颜色组列出将要移动的文件。拖动颜色组标题可调整颜色组顺序。拖动时页面靠近上下边缘会自动滚动，Esc 取消。
- 颜色组列表（`ui/pages/group/Outline.jsx`，颜色组很多时用；开关按分组保存）：工具栏最左侧的“列表”按钮打开 / 收起——正好在列表出现的位置上方，图标的三个圆点是前三个颜色组的颜色；也可以按 G。快捷键 G 不标在按钮上，而是标在列表查找框的末尾：查找框为空时一直显示（获得焦点时也不隐藏，所以点按钮打开列表时就能看到，并在列表出现后稍晚一点浮现），输入后换成清除按钮。在文件左侧停靠一列，随页面吸附，列表自己滚动。
  - 查找：打开时光标在查找框里，输入即按名称筛选（多个词都要包含，命中部分标出），↑ ↓ 选择、回车或单击跳到该颜色组（跨分页时先翻页）；屏幕上的颜色组被柔和的光框框住，列表随页面滚动跟随（指针在列表上、正在查找或拖动时不跟随）。
  - 排序：拖动行调整顺序（列表靠近上下边缘自动滚动，越停越快）；Ctrl / Shift 单击可选中多个一起拖动，底部出现操作栏：移到最前、移到最后、只展开这些；查找框里 Alt ↑ ↓ 把当前行（或选中的一批）移动一位，Alt Shift ↑ ↓ 移到最前 / 最后；“排序”可一次按名称（A→Z / Z→A，数字、拉丁字母、汉字按拼音、假名各自成组）、文件数、颜色重排全部颜色组。筛选时拖动或移动也按显示出来的相邻颜色组定位，在完整顺序里同样成立。修改立即生效（乐观更新），批量的移动与排序在提示里可撤销。
  - 每行悬停出现收起 / 展开按钮，按住 Alt 点击则只展开这一个（其余全部收起）。打开列表时工具栏的颜色组条隐藏（重复）；窄屏时列表浮在文件上方。
  - 编辑：“排序”旁的“编辑”打开编辑颜色组窗口；每行悬停出现的笔形按钮（或在查找框里对当前行按 F2）直接打开到这个颜色组——它在列表中间，名称已选中可直接改名，并按自己的颜色亮一下。
- 删除：图块菜单和底部操作栏的删除需要二次确认（扇形叠放将被删除的文件）；删除后可在提示里撤销。重新索引弹出选择：标签（保留手动标签）、图像索引、元信息，标签模型未下载时标签项不可选并引导到设置。
- 上传：上传按钮或把图片 / 视频拖到页面任意位置（页面内部的拖动不会触发）；非图片或视频的文件会被略过并提示。
- 下载：使用设置里的“下载文件命名”。单个文件直接保存；多个文件由“打包下载”任务完成（任务面板显示进度）。
- Ctrl + 滚轮在文件上调整图块尺寸；页面顶部的分页安静小巧（‹ 2 / 7 ›），底部是完整的页码。

## 灯箱

- 夜色房间：深色背景上铺一层由当前图片模糊而成的微光、四周略暗，三者作为一层（`.room`）一起淡入淡出，关闭时页面均匀地亮起来，不会在最后一刻突然变亮。控件在指针静止约 2.6 秒后隐去。默认按最大可用尺寸显示；图片（整个 `.media`，含原图层）与首页“上次浏览”的缩略图、随机一张抽中的牌共享名称 `file-art-<id>`，随页面到达时（`withPage`）由换页把它带进来，灯箱自己不再淡入；随页面到达时这张图片会让换页等它解码（最多约 0.8 秒），这是唯一让换页等待的图片。
- 打开与关闭：图片从图块的位置放大打开，关闭时缩回图块——均匀缩放并按图块的方式裁切（方形、极端比例的图块也不会被压扁），落定的一刻灯箱即隐去。在灯箱里切换文件时，分组页在夜色下面悄悄跟随，让当前文件的图块保持在视野内（图块已绘制、图片已加载）；关闭时若图块仍不在视野内，分组页先在灯箱下面瞬间滚动到它（`Grid` 的 `revealFile`，由布局算出位置，不必等图块绘制），再让图片飞回去。放大查看时关闭则随房间一起淡出。
- 与顶栏交接：灯箱打开时在根元素上标记 `data-lightbox`，页面顶栏随之淡出并上移，灯箱自己的顶栏稍后从上方落到同一位置；开始关闭时标记立即撤下，页面顶栏随灯箱淡出回到原位。切换文件、幻灯片换张时顶栏不会再闪现。
- 缩放：滚轮以指针为中心缩放，放大后可拖动，双击在适应屏幕与放大之间切换；右下角安静的缩放条（拖动条、百分比、一键回到适应屏幕）。
- 切换：←→ / ↑↓、两侧的箭头、Home / End。灯箱与幻灯片只走分组页当前显示的文件，顺序与页面上一致：收起的颜色组、超出每组限量的文件、其他分页的文件都会跳过，用户在分组页上看到什么，灯箱里就放什么。从首页（上次浏览、随机一张）打开的文件如果在其他分页，分组页先翻到那一页；如果被收起或限量隐藏，它会按自己在分组顺序中的位置临时插在显示的文件之间，离开后不再回到它。关闭后该文件的图块亮一下。
- 幻灯片：每张时长可直接输入（1–300 秒的整数，弹层打开时输入框已选中，回车即开始），也可用两侧的 −1 / +1 调整（按住连续加减，输入时 ↑ ↓ 或滚轮也可），下方有 3 / 5 / 8 / 12 / 20 秒的快捷选项；空格暂停 / 继续，Esc 停止；每张从夜色中浮现并缓慢推近，底部一条带微光的金色细线显示本张剩余时间，到末尾后从头循环。
- 详情（I 键或右上角）：分组、颜色组（可直接改到其他颜色组）、分辨率、大小、时长、创建日期、上传日期、标签与备注（可编辑保存；手动标签为暖色并带笔形图标，模型标签底部有一条表示置信度的细线；添加标签时从已有标签中提示）、ComfyUI 参数（模型、正 / 负向提示词可复制、种子可复制、采样器、调度器、步数、CFG、降噪强度；没有时不显示）。
- 加入封面、下载、删除（无需确认，可在提示里撤销，删除后自动显示下一个文件）。加入封面后按钮不再保持按下，而是换成一个金色标记（“封面 N”或“主封面”，刚加入或设为主封面时星光闪一下，并有提示），点击标记可设为主封面或移出封面；详情里的标签同样显示它是第几张封面。视频不能作封面。视频自动播放、循环，底部有安静的播放条。

## 颜色组

- 分组页工具栏的颜色组按钮 → 编辑颜色组（`ui/features/colors/ColorGroupsDialog.jsx`）：左侧是配置列表（新建、切换），右侧是所选配置的颜色组：改名、选颜色（12 种柔和色或任意颜色）、拖动排序、添加、删除（提示其中的文件会离开）。顶部的棱镜把分组的文件按颜色组“分光”成一条色带，随编辑实时变化。保存会保存所有配置并在页面上使用所选的配置（也可以选择不使用颜色组）。
- 颜色组很多时：列表上方有查找框（筛选时拖动仍按显示出来的相邻颜色组定位）与“排序”（与颜色组列表相同的排序方式）；编辑名称时 Alt ↑ ↓ 移动一位，Alt Shift ↑ ↓ 移到最前 / 最后；行更紧凑、列表更高；添加颜色组时清空查找并把光标放进新颜色组的名称。排序规则在 `data/domain/colorOrder.js`（移动一批、移动一位、整体排序、名称查找），颜色组列表与编辑窗口共用；拖动列表行用 `ui/lib/useListDrag.js`。
- 搜索结果里的颜色组：选中后打开所在分组并直接跳到该颜色组；它属于其他配置时，分组页先改用那个配置（`ui/lib/arrival.js` 在搜索与分组页之间传递）。

## 模拟层的行为

| 功能 | 模拟层的行为 |
| --- | --- |
| 样例图库 | 27 个分组、约 3400 个文件（含视频、ComfyUI 元信息、模型标签与手动标签、颜色组配置），按当天日期确定生成；大多数分组选好了 3–6 张封面，“未整理”由 Prism 自动挑选封面 |
| 持久化 | 设置（语言、主题）、首页的封面比例、分组顺序、上次浏览存在浏览器存储里（对应后端的 config.toml / sqlite）；新增、修改、删除分组只保存在内存中，刷新后回到样例库 |
| 以文搜图 / 以图搜图 | 需要后端具备图像索引，默认锁定。地址加上 `?image-search`（如 `http://localhost:5191/?image-search#/`）可模拟已建好索引的后端：以文搜图按画面内容与色调匹配，以图搜图按图片的整体色调匹配 |
| 任务 | 预置一个进行中的“重新索引”和一个排队中的“导入文件”；导入运行时文件会逐个加入“未整理”分组，首页的数量随之变化。任务分道执行，每道同时只跑一个：图库（导入、重新索引）、上传、文件（导出、打包下载）、模型下载、快照，互不排队。任务进度最多每 0.5 秒推送一次（开始、结束等状态变化立即推送），避免频繁重绘打断页面切换 |
| 分组页 | 每次修改图库都会更新版本号，分组页每 5 秒带着版本号来要数据，没有变化时只返回版本号。页面设置（排序、排版、限量……）按分组保存在浏览器存储里（对应数据库）；文件的标签、备注、颜色组、自定义顺序与颜色组配置的修改保存在内存中（会出现在数据备份的更改里），刷新后回到样例库。“星空与夜景”“Pixiv 收藏 · 风景”等分组有颜色组配置；“Pixiv 收藏 · 风景”的第二个配置“画师”有 120 个颜色组（少数画师文件很多、多数只有几张），用来查看颜色组很多时的列表、查找与排序；“草稿”是空分组 |
| 上传与下载 | 上传的图片 / 视频真的会被读取（尺寸、视频时长与封面帧），在“上传”任务里逐个加入分组，本次会话内可正常浏览；下载单个文件时把生成的画作按原尺寸与格式渲染成文件交给浏览器保存，多个文件以“打包下载”任务模拟 |
| 首次启动引导 | 配置里尚未完成引导时自动打开；地址加上 `?first-run`（如 `http://localhost:5191/?first-run#/`）可再看一次。只有引导结束时才保存选择，密钥除外（点击“创建密钥”时就创建，便于立刻复制） |
| 登录页 | 开启密码登录后打开页面即进入；会话存在 `sessionStorage`，新标签页需要重新登录；“设置 → 访问与安全 → 立即锁定”可直接回到登录页；连续输错 5 次需等待 30 秒。“忘记密码”说明在 Prism 终端输入 `/reset_pwd`，或在 `config.toml` 中关闭密码保护（由后端实现）。模拟层为了校验会保存明文，后端只应保存哈希 |
| 服务器模式 | 设置 → 访问与安全；开启后顶栏出现服务器按钮（地址与二维码）。后端启动时读取该设置，所以开关后要重启才生效；模拟层把“刷新页面”当作重启 |
| MCP | 设置 → MCP → 管理密钥。密钥保存在模拟配置里（样例含 3 个）；完整密钥只在创建与重新生成时返回一次。权限分三类：分组（查询、修改信息、删除）、颜色组（查看、创建、修改信息、删除）、文件（查询、添加、修改信息、删除）；预设“整理”= 查询 + 修改信息 + 创建颜色组 |
| 数据备份（快照） | 设置 → 数据与备份 → 数据备份。备份粒度为分组：创建快照时选择包含哪些分组（默认选中有更改的分组，已删除的分组也可选，以便保存删除）；页面设置与导出配置属于整个图库，总会一起保存。每个快照记录当时的分组与文件：载入较早的快照会让样例库真的回到当时（未保存到快照的内容会丢失），被删除的分组与文件仍由快照保管；删除快照只是从时间线隐藏，可撤销；`D:\Prism\backup` 里预置了一个可导入的 `.prsnap` 快照文件，导出的文件也会出现在所选文件夹中 |
| 导出 | 首页导出整个图库（文件类型来自全部文件），分组页导出已包含当前分组（文件类型来自所选分组）；按导入日期筛选，日历上的点表示当天导入的文件数。默认文件名为“分组名称 / 颜色组名称 / 原文件名”（不属于任何颜色组的文件直接放在分组目录里）。每个页面的上一次配置会记住（乐观保存） |
| 标签模型 | 列表与状态来自后端：EVA02-Large v3 默认已下载并使用中；“重新下载”需二次确认，会先删除模型文件再下载（任务面板与设置里实时显示进度，可取消） |
| 数据库路径 | 设置 → 数据与备份；改为其他目录会切换到一个空库，可用来查看空状态；改回默认路径即恢复样例库 |
